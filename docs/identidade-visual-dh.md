# Identidade visual da DH Financeira

O nome, as cores e os materiais deste projeto pertencem à DH Financeira. As imagens usadas pelo site ficam em `public/brand/dh-*`; a marca vetorial do painel fica em `src/assets/dh-horizontal.svg` e `src/assets/dh-symbol.svg`.

O app mantém suporte a marcas personalizadas por conta. Quando uma configuração antiga contém apenas o nome padrão do produto anterior, a interface exibe DH Financeira. Nomes personalizados de cada cliente continuam preservados.

Os arquivos de marca legados foram removidos. As chaves locais antigas são migradas uma vez para o namespace `dhfinanceira` para preservar sessões offline e itens ainda não sincronizados.
